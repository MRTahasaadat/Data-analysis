# Data Analysis Libraries Introduction
# معرفی کتابخانه‌های تحلیل داده

This folder contains a collection of tutorials and examples for essential and widely used libraries in data analysis. The goal is to familiarize you with how to use these tools in real-world projects.

این پوشه شامل مجموعه‌ای از آموزش‌ها و مثال‌ها برای کتابخانه‌های اصلی و پرکاربرد در تحلیل داده است. هدف این مجموعه، آشنایی شما با نحوه استفاده از این ابزارها در پروژه‌های واقعی است.

**Libraries Introduced:**
**کتابخانه‌های معرفی شده:**

*   [NumPy](Introduction of libraries/numpy.py) -Numerical computations and array manipulation (محاسبات عددی و کار با آرایه‌ها)
*   [Pandas](Link to Pandas Tutorial) - Data analysis and manipulation(تحلیل و دستکاری داده‌ها)
*   [Matplotlib](Link to Matplotlib Tutorial) - Plotting and data visualization(رسم نمودار و تجسم داده‌ه)
*   [Seaborn](Link to Seaborn Tutorial)  - Advanced statistical data visualization(تجسم داده‌های آماری پیشرفته)
*   [Scikit-learn](Link to Scikit-learn Tutorial) - Machine learning algorithms(الگوریتم‌های یادگیری ماشین)

**How to Use:**
**نحوه استفاده:**

Each library is located in a separate folder. Within each folder, you can find the README.md file, tutorial notebooks (notebooks), and practical examples (scripts).

هر کتابخانه در یک پوشه جداگانه قرار دارد. در هر پوشه می‌توانید فایل README.md، نوت‌بوک‌های آموزشی (notebooks) و مثال‌های عملی (scripts) را پیدا کنید.

**مشارکت:**

خوشحال می‌شویم اگر در بهبود این مجموعه مشارکت کنید. پیشنهادات و اصلاحات خود را از طریق Pull Request ارسال کنید.
