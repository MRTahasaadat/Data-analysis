

Iran City Population Map - Interactive Data Analysis Project

توضیح کلی پروژه

این پروژه یک تحلیل تعاملی از جمعیت ده شهر بزرگ ایران است. با استفاده از کتابخانه‌های matplotlib، pandas و geopandas، نقشه‌ای از ایران رسم می‌شود و موقعیت جغرافیایی شهرهای بزرگ روی آن نمایش داده می‌شود. کاربر می‌تواند روی هر شهر کلیک کند و نمودار جمعیت آن را مشاهده نماید.

ابزارهای استفاده‌شده

Python: زبان اصلی پروژه

matplotlib: رسم نقشه و نمودارها

mplcursors: افزودن تعامل کلیکی

pandas: مدیریت داده‌ها

geopandas: بارگذاری نقشه ایران

نحوه اجرا

نصب کتابخانه‌ها با دستور زیر:

pip install matplotlib pandas geopandas mplcursors 

دانلود فایل نقشه ایران (iran.geojson یا shapefile) و قرار دادن آن در مسیر پروژه.

اجرای برنامه:

python iran_population_map.py
